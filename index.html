Advanced mechanics
Each block cues one stream to focus on without dropping the others, rotating through them. Practising the priority shift itself is what transfers better than steady equal emphasis.
Report how this move relates to the move you reported N trials ago — same, opposite, or a different axis — instead of which way it went. Forces every move to be axis-aligned, otherwise "same/opposite" has no answer for a diagonal. Punishing above N=2.
Dashed orange cells must be judged but not remembered — they never become anyone's N-back item. Trains holding the gate shut, which ordinary N-back never asks for.
The lag is drawn fresh every trial and shown above the answer keys — at N 3 ±1 you are asked for 2-back, 3-back or 4-back, in no order. A fixed N can be held as a rehearsal loop; this cannot, so the whole recent window has to stay addressable and you have to re-aim inside the interval. Targets and lures are planted at whatever lag the trial drew, so mis-reading the cue costs you the answer. Can't combine with the retro-cue, which replaces the n-back rule outright.
The stimulus vanishes, then a cue names which adjacent pair to report. You must hold every recent item, not just the one N-back would have picked. Overrides N, can't combine with meta-relations, and forces the interval to at least 1.30s so there is time to answer after the cue.
Normally the 2×2 map of symbol sets reshuffles every session so it must be re-learned. Fixed keeps one layout forever — much easier, and it removes the re-memorisation the shuffle is there to force.
Share of trials that match N±1 but not N — familiarity says yes, recollection says no.

Display
Counts time inside blocks only, and ticks live while you play. Turns green once you hit it.
Two distinct error sounds: a descending slide for a wrong press, two low pulses for a miss (a target you never answered). Independent of the Feedback setting, so you can keep the audio cue with the visuals off.
Spaced layout scales its spread to match, so a bigger cube means bigger gaps rather than just bigger cells.

A key shown in red is one a response button is currently using — that button answers first, so the shortcut stays dead until the stream is switched off.
